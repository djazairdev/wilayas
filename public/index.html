wilayas

Algeria's 69 wilayas, their daïras and 1,541 communes, as a free, read-only API built from the official texts in the Journal officiel. Every record cites its text.

  • /v1/index.json: the list of files
  • /v1/wilayas.json, /v1/communes.json, /v1/changes.json
  • The API docs, where every path can be tried, and /v1/openapi.json, the OpenAPI description they show

Data: CC0 1.0. Code: MIT. Source and documentation: github.com/djazairdev/wilayas.

This is not an official government service.
